The "network 7 layers" refers to the [OSI model](https://www.google.com/search?q=OSI+model&oq=network+7+%3B&gs_lcrp=EgZjaHJvbWUqBwgBEAAYgAQyBggAEEUYOTIHCAEQABiABDIHCAIQABiABDIHCAMQABiABDINCAQQLhivARjHARiABDIHCAUQABiABDIGCAYQRRhBMgYIBxBFGDzSAQg3NDE4ajBqOagCALACAfEFjYe3WvW2zRE&sourceid=chrome&ie=UTF-8&ved=2ahUKEwiXxv_ToJaRAxUY38kDHR7VDqoQgK4QegYIAQgAEAU), a conceptual framework for network communication that breaks the process into seven distinct layers. These layers, from bottom to top, are the Physical, Data Link, Network, Transport, Session, Presentation, and Application layers. Each layer handles a specific set of tasks, from raw data transmission at the physical layer to user-facing services at the application layer. 

The 7 layers of the OSI model

-   [Physical Layer](https://www.google.com/search?q=Physical+Layer&oq=network+7+%3B&gs_lcrp=EgZjaHJvbWUqBwgBEAAYgAQyBggAEEUYOTIHCAEQABiABDIHCAIQABiABDIHCAMQABiABDINCAQQLhivARjHARiABDIHCAUQABiABDIGCAYQRRhBMgYIBxBFGDzSAQg3NDE4ajBqOagCALACAfEFjYe3WvW2zRE&sourceid=chrome&ie=UTF-8&ved=2ahUKEwiXxv_ToJaRAxUY38kDHR7VDqoQgK4QegYIAQgAEAw) (Layer 1): Deals with the physical connection, transmitting raw bits over a physical medium.
-   [Data Link Layer](https://www.google.com/search?q=Data+Link+Layer&oq=network+7+%3B&gs_lcrp=EgZjaHJvbWUqBwgBEAAYgAQyBggAEEUYOTIHCAEQABiABDIHCAIQABiABDIHCAMQABiABDINCAQQLhivARjHARiABDIHCAUQABiABDIGCAYQRRhBMgYIBxBFGDzSAQg3NDE4ajBqOagCALACAfEFjYe3WvW2zRE&sourceid=chrome&ie=UTF-8&ved=2ahUKEwiXxv_ToJaRAxUY38kDHR7VDqoQgK4QegYIAQgAEA4) (Layer 2): Manages data framing and error correction over a physical link.
-   [Network Layer](https://www.google.com/search?q=Network+Layer&oq=network+7+%3B&gs_lcrp=EgZjaHJvbWUqBwgBEAAYgAQyBggAEEUYOTIHCAEQABiABDIHCAIQABiABDIHCAMQABiABDINCAQQLhivARjHARiABDIHCAUQABiABDIGCAYQRRhBMgYIBxBFGDzSAQg3NDE4ajBqOagCALACAfEFjYe3WvW2zRE&sourceid=chrome&ie=UTF-8&ved=2ahUKEwiXxv_ToJaRAxUY38kDHR7VDqoQgK4QegYIAQgAEBA) (Layer 3): Handles logical addressing and routing data packets across networks.
-   [Transport Layer](https://www.google.com/search?q=Transport+Layer&oq=network+7+%3B&gs_lcrp=EgZjaHJvbWUqBwgBEAAYgAQyBggAEEUYOTIHCAEQABiABDIHCAIQABiABDIHCAMQABiABDINCAQQLhivARjHARiABDIHCAUQABiABDIGCAYQRRhBMgYIBxBFGDzSAQg3NDE4ajBqOagCALACAfEFjYe3WvW2zRE&sourceid=chrome&ie=UTF-8&ved=2ahUKEwiXxv_ToJaRAxUY38kDHR7VDqoQgK4QegYIAQgAEBI) (Layer 4): Ensures reliable data transfer between end systems, managing flow control and segmentation.
-   [Session Layer](https://www.google.com/search?q=Session+Layer&oq=network+7+%3B&gs_lcrp=EgZjaHJvbWUqBwgBEAAYgAQyBggAEEUYOTIHCAEQABiABDIHCAIQABiABDIHCAMQABiABDINCAQQLhivARjHARiABDIHCAUQABiABDIGCAYQRRhBMgYIBxBFGDzSAQg3NDE4ajBqOagCALACAfEFjYe3WvW2zRE&sourceid=chrome&ie=UTF-8&ved=2ahUKEwiXxv_ToJaRAxUY38kDHR7VDqoQgK4QegYIAQgAEBQ) (Layer 5): Establishes, manages, and terminates sessions between applications.
-   [Presentation Layer](https://www.google.com/search?q=Presentation+Layer&oq=network+7+%3B&gs_lcrp=EgZjaHJvbWUqBwgBEAAYgAQyBggAEEUYOTIHCAEQABiABDIHCAIQABiABDIHCAMQABiABDINCAQQLhivARjHARiABDIHCAUQABiABDIGCAYQRRhBMgYIBxBFGDzSAQg3NDE4ajBqOagCALACAfEFjYe3WvW2zRE&sourceid=chrome&ie=UTF-8&ved=2ahUKEwiXxv_ToJaRAxUY38kDHR7VDqoQgK4QegYIAQgAEBY) (Layer 6): Translates, encrypts, and compresses data to be used by the application layer.
-   [Application Layer](https://www.google.com/search?q=Application+Layer&oq=network+7+%3B&gs_lcrp=EgZjaHJvbWUqBwgBEAAYgAQyBggAEEUYOTIHCAEQABiABDIHCAIQABiABDIHCAMQABiABDINCAQQLhivARjHARiABDIHCAUQABiABDIGCAYQRRhBMgYIBxBFGDzSAQg3NDE4ajBqOagCALACAfEFjYe3WvW2zRE&sourceid=chrome&ie=UTF-8&ved=2ahUKEwiXxv_ToJaRAxUY38kDHR7VDqoQgK4QegYIAQgAEBg) (Layer 7): Provides network services directly to the user and includes applications like web browsers and email clients.
